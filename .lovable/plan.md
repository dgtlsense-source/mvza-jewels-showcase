# MVZA Jewels Opening Website

## Experience
- Create a single-page, classic luxury website led by an original slow-motion antique gold jewellery film.
- Overlay the MVZA mark, opening date, and a live countdown on the film.
- Add a tactile “Reveal the venue” interaction showing the Ahmedabad address and a map link.
- Add an invitation request area collecting name and phone number.
- Include Instagram and Facebook links in a discreet footer; use safe placeholders until real profile links are supplied.

## Visual direction
- Museum-like black and warm ivory foundation with restrained antique-gold detailing.
- Refined editorial serif paired with a quiet modern sans serif.
- Slow, deliberate motion and fine ornamental lines; no generic cards or busy effects.

## Technical details
- Preserve the uploaded logo as the brand mark and derive the site icon from it.
- Store invitation requests securely with Lovable Cloud.
- Make the full experience responsive and accessible, including reduced-motion behavior.
- Add page metadata for MVZA Jewels and verify the finished page on desktop and mobile.
